# Python Text Analyzer

A beginner-friendly Python project that analyzes a paragraph entered by the user.

## Features
- Counts total characters
- Counts total words
- Finds the longest word
- Counts vowels
- Calculates word frequency
- Finds the most frequently used word

## Concepts Used
- Variables and input
- Strings and string methods
- Lists and dictionaries
- For loops
- If-else conditions
- Functions
- Dictionary methods (`.items()`)

## How to Run

```bash
python main.py
```

## Learning Goal

Built to practice Python fundamentals through a practical text-analysis program.
